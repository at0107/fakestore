# 🛒 E-Commerce Web Application (FakeStore)

A fully responsive and dynamic e-commerce storefront built to demonstrate client-server communication, asynchronous requests, and modern UI/UX practices.

## ✨ Key Features
- Dynamic product data fetching from FakeStore REST API
- Fully responsive design for mobile and desktop
- Clean and intuitive user interface 

## 🛠 Tech Stack
- **Framework:** Next.js, React
- **Language:** TypeScript
- **Styling:** Tailwind CSS / CSS

## ⚙️ Getting Started

To run this project locally:

1. Clone the repository:
   ```bash
   git clone [https://github.com/at0107/fakestore.git](https://github.com/at0107/fakestore.git)
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```
